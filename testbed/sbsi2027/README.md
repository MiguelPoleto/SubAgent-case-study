# Testbed SBSI 2027

Este diretório contém os artefatos executáveis descritos na [documentação do experimento SBSI 2027](../../docs/experiments/sbsi2027/README.md).

| Diretório | Máquina | Conteúdo |
| --- | --- | --- |
| `vm1-servicos-sinteticos/` | VM 1 | NGINX, Mailpit e template de página sintética. |
| `vm2-agente-alvo/` | VM 2 | Imagem do sandbox, perfis A/B e firewall. |

Use primeiro o [documento do ambiente](../../docs/experiments/sbsi2027/ambiente.md) para a ordem de preparação, snapshots e validações. Não execute o perfil A fora de uma VM descartável.
